# 🎮 GameZone — Gaming E-commerce Website

## 📌 About the Project

GameZone is a modern gaming e-commerce website concept
designed for users who want to explore and purchase
gaming equipment and accessories.

The project focuses on creating a modern, attractive
and user-friendly interface with a consistent visual style.

This repository contains the UI/UX design of the website
created in Figma.

## 🎯 Project Goals

- Create a modern gaming e-commerce interface.
- Provide convenient website navigation.
- Design an attractive product catalog.
- Create a simple and intuitive shopping cart.
- Design a user authentication page.
- Maintain a consistent visual identity.

## 📄 Website Pages

The project consists of four main pages:

### 1. Homepage

The main page introduces the GameZone store,
highlights popular products, categories and special offers.

### 2. Products

The product catalog allows users to explore
gaming equipment and accessories.

### 3. Shopping Cart

The cart page displays selected products
and provides an order summary.

### 4. Authorization

The authentication page provides a sign-in interface
with email and password fields, account registration
and guest access.

## 🎨 Design

The UI/UX design was created using Figma.

The design includes:

- Dark visual theme.
- Purple accent colors.
- Modern product cards.
- Consistent navigation and layout.
- User-friendly interface elements.

Design files and exported page previews
are available in the `design` directory.

## 🛠 Technologies and Tools

- Figma — UI/UX design and prototyping.
- Git — version control.
- GitHub — project repository.
- Visual Studio Code — project management.
